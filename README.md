**Soccer nested dictionaries project**

- This is a project I worked on in my HS CSP2 class. It is a project on nested dictionaries. I decided to have a soccer player goal dictionary, and you can use a lot of different methods on it.
- My program performs 3 calculations. It can find the average goals of the top 3 scorers from a team, compare the goalscoring numbers of 2 players, and calculate a team rating based on its goals.
- During my coding process, I had an issue with replacing entire key-value pairs in a dictionary. It would either be a very lengthy process, or the code would contain an error. Luckily, I searched it up and learned that it can be solved with .pop().
- In the future, I would probably add more error messages, and maybe I would use an API to create the dictionary.
